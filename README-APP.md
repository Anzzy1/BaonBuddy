# BaonBuddy as an installable app

BaonBuddy now runs as a real offline app on **Android (APK)** and **Windows (EXE)**.
The Next.js project is exported as static files, so no server is needed at runtime.

## What changed

- The old `/api/*` routes were moved client-side into `lib/engine.ts`, `lib/feedback.ts`
  and `lib/ollama.ts`, so expense parsing, receipt parsing, Buddy advice and feedback
  all work without a server.
- `next.config.ts` uses `output: 'export'` → the build produces `out/`.
- **Capacitor** wraps `out/` into the Android app (`android/`).
- **Electron** wraps `out/` into the Windows app (`desktop/`).
- Optional local AI: if Ollama is running at `http://localhost:11434`, Buddy uses it for
  nicer English replies. Otherwise everything falls back to instant rule-based answers.
- Camera + microphone permissions and an app icon/splash were added for Android.

## Build the Android APK

Requirements (already set up on this machine):

- JDK 21 → `C:\Users\Anzyy Dev\Android\jdk21`
- Android SDK → `C:\Users\Anzyy Dev\Android\sdk` (platform 36, build-tools 36.0.0)

```powershell
npm run android:build
```

The APK lands at:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

A ready-to-install copy is also kept at:

```
BaonBuddy.apk
```

### Install on the phone

1. Copy `BaonBuddy.apk` to the phone (USB cable, Google Drive, or send it to yourself).
2. Tap the file. If Android asks, allow **Install unknown apps** for the Files app or
   browser you used.
3. Tap **Install** → **Open**. The BaonBuddy icon appears in the app drawer.

It is a debug build, so it is signed and installable without Play Store.

### If Android Studio / SDK paths change

Edit `android/local.properties`:

```properties
sdk.dir=C:/Users/Anzyy Dev/Android/sdk
```

## Build the iOS app (no Mac needed)

iOS apps can only be compiled with **Xcode**, which runs on macOS. This project includes a
GitHub Actions workflow that builds the `.ipa` on a free cloud Mac, and the result is signed
and installed from Windows with **Sideloadly** and your Apple ID. No App Store, no $99 fee
required for personal use.

### iOS look (Liquid Glass)

The iOS app has its own iOS 26 style shell, separate from the Android/Windows UI:
a floating Liquid Glass tab bar with a lens you can tap or drag between tabs (it slims
while scrolling down), a round glass **+** button for logging, large titles that collapse
into the nav bar, glass toolbar buttons, bottom sheets with a grabber, and haptic
taps via `@capacitor/haptics`. It switches on automatically when running on iOS
(`lib/platform.ts`), styled by `app/ios.css` and `components/ios/IOSChrome.tsx`.

Preview it in a browser with `npm run dev` → `http://localhost:3000/?ui=ios`
(`?ui=default` switches back).

### 1. Cloud-build the IPA

1. Push this project to GitHub (the `ios/` folder must be included).
2. Open the repo on GitHub → **Actions** → **iOS unsigned build** → **Run workflow**.
3. When it finishes, open the run → **Artifacts** → download **BaonBuddy-unsigned-ipa**.
4. Unzip it to get `BaonBuddy-unsigned.ipa`.

It is unsigned on purpose — Sideloadly signs it with your Apple ID during install.

### 2. Install on the iPhone from Windows

1. Install [Sideloadly](https://sideloadly.io) on the laptop and the Apple Devices/iTunes
   driver it asks for.
2. Connect the iPhone by USB and tap **Trust** on the phone.
3. Drag `BaonBuddy-unsigned.ipa` into Sideloadly, enter your **Apple ID**, click **Start**.
4. On the iPhone: **Settings → General → VPN & Device Management** → tap your Apple ID →
   **Trust**.
5. iOS 16+: **Settings → Privacy & Security → Developer Mode** → turn on → restart.

With a **free Apple ID** the app works for **7 days** (max 3 sideloaded apps), then reinstall
with Sideloadly. With a paid Apple Developer account ($99/yr) it lasts a year.

### If you do have a Mac

```powershell
npm run ios:sync
npx cap open ios
```

Select your team in **Signing & Capabilities** and press Run. The Xcode project is at
`ios/App/App.xcodeproj` (bundle ID `com.baonbuddy.app`, iOS 15+).

`ios/App/App/public/` is generated by `cap sync` — don't edit it by hand.

## Run / package the Windows app

```powershell
npm run desktop          # build + open the app window
npm run desktop:build    # build + create the portable app
npm run desktop:shortcut # add a BaonBuddy shortcut to the Desktop
```

Portable app:

```
release/BaonBuddy/BaonBuddy.exe
```

It is a self-contained folder: you can move or copy `release/BaonBuddy` anywhere and run
`BaonBuddy.exe`. Windows Smart App Control blocks freshly patched unsigned executables,
which is why this build keeps Electron's original signed/known binary instead of
rewriting its icon and metadata.

## Development

```powershell
npm run dev              # normal browser dev server at http://localhost:3000
npm run build            # static export into out/
npm run icons            # regenerate Android launcher icons from app/icon.svg
```

## Notes

- Data stays in local storage on the device. Nothing leaves the phone/laptop.
- Voice logging uses an offline Whisper model bundled in `public/models` (~130 MB).
  In the Android WebView, multi-threaded WebAssembly may be unavailable, so voice
  recognition can be slower or unavailable depending on the device. Chat/manual/scan
  logging work everywhere.
- The debug APK includes the full offline model, so it is fairly large.
